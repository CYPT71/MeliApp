# Règles de catégories

1. Une feature appartient à zéro ou une catégorie produit.
2. Plusieurs features d’une catégorie partagent la même route.
3. Les routes de catégories doivent être uniques.
4. Les widgets d’accueil n’ont ni `page` ni `category`.
5. Une déclaration `category` directement sur la feature est prioritaire sur le mapping produit.
