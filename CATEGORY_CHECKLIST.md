# Checklist catégories

Avant d’ajouter une nouvelle catégorie :

- [ ] vérifier qu’une catégorie existante ne couvre pas déjà le besoin ;
- [ ] donner une route hash stable ;
- [ ] éviter deux catégories avec la même route ;
- [ ] garder un titre court pour mobile ;
- [ ] vérifier qu’au moins une feature de la catégorie possède une UI ;
- [ ] garder les features purement techniques invisibles mais rattachables à la catégorie ;
- [ ] ajouter ou adapter un test de routage ;
- [ ] mettre à jour les raccourcis PWA seulement si la catégorie mérite un accès direct.
